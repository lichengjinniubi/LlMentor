- `service/pom.xml` → 父 pom（packaging=pom），聚合 `ai-framework` + `ai-service`，dependencyManagement 收纳 spring-ai-alibaba-bom 1.1.0.0、spring-ai 1.1.0、mysql 8.0.33
- 现有代码 `git mv` 迁入 `ai-service/`（包名不变 com.ai.service，保留 git 历史）
- 新建 `ai-framework/`：com.ai.framework.AiFrameworkApplication，端口 8081（ai-service 用默认 8080）
- 构建踩坑记录：
  1. 原 pom 的 spring-ai-alibaba-bom 放在 `<dependencies>` 里用 import scope 是无效位置（import 只在 dependencyManagement 生效）；且该 BOM 1.1.0.0 并不管理 dashscope starter 坐标，需在父 pom 显式声明版本
  2. shell 默认 JAVA_HOME 是 JDK 8，构建需 JAVA_HOME 指向 ms-21.0.11
  3. ~/.m2/settings.xml 镜像全部指向公司内网 Nexus（maven.wemomo.com，需 VPN）；离线时用仓库根的 `.mvn-aliyun-settings.xml` 走阿里云：`./mvnw -s .mvn-aliyun-settings.xml package`
- 构建验证通过：两个子模块均打出可执行 jar；ai-framework 干净环境下正常监听 8081（沙箱里 SERVER__PORT=0 会让端口随机，属验证环境干扰，不影响用户本机）
